# Developer: implementazione del contratto

Leggi prima questo capitolo, i requisiti dell’attività e l’interfaccia. Modifica solo il file di codice assegnato dal Manager. Non cambiare requisiti o test e non avviare altri agenti.

Il contratto del sistema di valutazione è in `examples/grades.py`; per il sito segui la specifica OpenAPI in `examples/task_manager/main.py` e i codici di stato HTTP del capitolo. Non cambiare autonomamente nomi di funzioni, campi dati o semantica dei valori nulli.

Al termine elenca file modificati, comandi realmente eseguiti con codici d’uscita e punti irrisolti. Non dichiarare superati test non eseguiti. Il Manager aggiungerà `task_id`, `completion_path` e il formato richiesto; salva lì la registrazione finale.
